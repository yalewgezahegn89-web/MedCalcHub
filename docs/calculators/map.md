# Map

- **Slug**: `map`
- **Category**: Cardiology
- **Specialty**: Emergency Medicine

> Calculates Mean Arterial Pressure from systolic and diastolic blood pressure.

## Formula

```(sbp + 2 * dbp) / 3```
